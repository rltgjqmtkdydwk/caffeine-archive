# 카페인 아카이브

지하철역 기준으로 카페를 모아 보는 지도 + 익명 후기 사이트.
카공(공부·작업)과 느좋(분위기·데이트) 두 종류로 나눠 놓음. 모바일 우선.

## 주요 기능

- 카공/느좋 필터, 역별 필터. 지도와 목록 연동
- 카페 상세: 평균 별점·분포, 카공/느좋 비율, 항목별 최다 응답, 후기 목록
- 후기: 별점만 필수. 자리 수, 소음, 콘센트, 이용 시간 제한, 마감, 디저트, 로스팅, 개성, 추구미, 한마디는 전부 선택. 카페당 사용자당 1개(다시 쓰면 수정)
- 카카오 로그인 + 사이트 전용 닉네임/모양 표시(8종)로 익명 유지

## 파일 구조

```
index.html          화면 뼈대
style.css           디자인 전부
app.js              지도, 필터, 목록, 카페 상세
reviews.js          로그인, 프로필, 후기 요약, 작성 폼
config.js           Supabase 주소와 공개 키 (비어 있으면 데모 모드)
data/cafes.json     카페와 역 목록 (직접 편집)
supabase/schema.sql 테이블, 트리거, 뷰, 권한
```

## 기술 선택

- 정적 사이트 + GitHub Pages: 빌드 도구 없음, 파일 수정 후 커밋하면 배포 끝
- Supabase 무료 플랜: 후기·프로필만 저장. 카카오 OAuth도 여기서 처리
- Leaflet + OpenStreetMap/CARTO 타일: 무료, API 키 불필요
- 길찾기는 네이버 지도/카카오맵 검색 링크로 넘김
- `config.js`가 비어 있으면 데모 모드: 가짜 로그인, 데이터는 해당 브라우저 localStorage에만 저장

## 익명성 설계

- 카카오 계정은 "같은 사람인지" 구분하는 용도로만 사용
- 후기에 붙는 건 사이트 전용 닉네임과 모양 표시뿐
- 카카오가 넘기는 이름·사진·이메일은 저장 직전에 트리거(`strip_kakao_profile`)가 제거
- 공개 조회는 `reviews_public` 뷰로만. 계정 id가 없어 후기와 사람을 연결할 수 없음
- 탈퇴 시 계정, 프로필, 후기가 연쇄 삭제
- `config.js`에는 anon/publishable 키만 사용

## 로컬 실행

```
python3 -m http.server 8000
```

http://localhost:8000 (`index.html`을 파일로 직접 열면 json 로드 실패)

## 카페 데이터 형식

`data/cafes.json`의 카페 항목. `walk`, `address`, `hours`, `tags`, `note`는 생략 가능. `id`는 후기가 붙는 키라 한번 정하면 변경 불가.

```json
{
  "id": "c11",
  "name": "카페 이름",
  "type": ["카공", "느좋"],
  "station": "sinchon",
  "lat": 37.5561, "lng": 126.9372,
  "walk": 3,
  "address": "서울 서대문구 ...",
  "hours": "09:00–22:00",
  "tags": ["콘센트", "조용함"],
  "note": "한두 줄 메모"
}
```

현재 들어 있는 10곳은 예시 데이터(`"sample": true`).
